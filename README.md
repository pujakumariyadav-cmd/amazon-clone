# Amazon Clone

A frontend clone of the Amazon e-commerce website built using HTML, CSS. This project replicates the look and feel of Amazon's homepage, including the navigation bar, search section, product categories, and footer.

## Features
- Responsive homepage design
- Amazon-style navigation bar
- Search bar and menu section
- Product category cards
- Hero banner section
- Footer with multiple links
- Clean and user-friendly interface

## Technologies Used
- HTML5
- CSS3

## Project Objective
The objective of this project is to improve frontend web development skills by recreating the user interface of a popular e-commerce platform.
